## 4. 范围与非目标

本MRD可支撑的决策 = 座舱语音助手迭代方向的候选清单。不可支撑 = 商业立项结论（市场规模、付费意愿、单位经济需另行验证）。决策目标继续兼顾助手迭代与新Agent机会，但机会只保留为待验证假设。

- 本轮候选范围：稳定唤醒、导航目标正确理解与任务完成、误触发与音区权限、唤醒设置支持、自然连续交互、快捷入口和失败补救；服务权益争议作为低置信度核查线索。
- 跨端协作仅开展具体任务访谈和验证，不直接建设跨服务编排、主动服务或长期记忆；这三项是本轮非目标。传统车控多指令不能直接证明这些需求。
- 不输出当前最新Agent整体表现、故障率、安全收益、需求覆盖率、品牌排名或留存结论；不把设置疑问认定为可复现故障，不把缺失市场/商业证据补成正式立项判断。
- 本次是旧探索性v1的评审修订，沿用原文四部分逻辑并插入范围节；不新增市场分析事实，不编写BRD或PRD。后续11部分MRD结构用于新研究，本轮不借扩写增加未经验证的结论。
