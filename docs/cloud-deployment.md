# 云端部署与验收

此配置把现有网页和研究API放在同一台云服务上，使用DeepSeek分析。默认使用Render免费实例，不创建付费磁盘；DeepSeek模型调用仍按模型账户计费。GitHub Pages继续承担静态示例展示。需要连接部署账号，并在云端验证真实来源和模型调用。

## Render 部署

1. 登录 Render，创建 Blueprint，选择本仓库的 `render.yaml`。也可打开 [部署入口](https://render.com/deploy?repo=https://github.com/kyyoki-stack/VOC_To_MRD)。
2. 预览资源：新加坡区域、一个Docker Web Service，方案必须显示 **Free**，没有磁盘、付费数据库或其他付费资源。当前模板不会创建这些付费资源。
3. 在 Render 的私有环境变量中填写 `DEEPSEEK_API_KEY`。不要填入仓库文件、前端代码或构建参数。会话密钥和第一个访问码由 Render 随机生成。
4. 使用 Render 分配的 HTTPS 地址访问首页。服务自动从 `RENDER_EXTERNAL_HOSTNAME` 确定允许的来源；自定义域名时设置 `VOC_PUBLIC_ORIGIN=https://实际域名`，不带路径或结尾斜线。
5. 私下获取 `VOC_ACCESS_CODES` 中的访问码，输入网页。每位试用者使用一个不同的随机码；多个码用逗号分隔，同码共享临时研究历史。不要把码公开贴到README。移除某个码会拒绝该码的旧会话（部署配置更新生效后）。
6. 完成下方云端验收后再对外分享实际服务地址。已有 Pages 地址不会自动获得后端；确认云地址后可将 Pages 入口指向云站。

此处只有一个 Web 实例和一个后台研究线程。自动部署已关闭，避免每次提交打断正在执行的研究；更新时选择没有进行中任务的窗口手动部署。不要增加 Gunicorn worker 或多个实例，否则任务调度模型需要先升级。

## 免费方案的使用方式

打开HTTPS网址 → 输入访问码 → 输入主题并回车 → 保持页面打开等待进度 → 完成后及时下载数据报告、MRD和CSV。研究结果链接只能在当前服务实例仍保留文件时使用，不应当作长期分享链接。

Render免费服务15分钟没有入站流量会休眠，下次访问约需一分钟唤醒。休眠、重启或重新部署会清空本地文件，包括SQLite、任务状态、评论和报告。页面正常打开并轮询时会向服务发送请求，但这不保证平台不会重启服务。免费服务不能挂持久磁盘。

免费实例小时每工作区每月750小时，另有带宽和构建额度。若未添加支付方式，相关额度用完会暂停服务或新构建；若已添加支付方式，带宽／构建超量可能产生费用，需检查工作区消费设置。免费方案不保证持续可用。不要配置定时访问来绕过休眠限制。[官方免费方案限制](https://render.com/docs/free)

## 数据、额度与恢复

- 会话 Cookie 使用 HTTPS、HttpOnly 和 SameSite=Lax；写入接口还校验 Origin 与 CSRF 令牌。
- 数据库、任务状态和研究文件都在 `/data/research-runs` 目录。默认免费实例中这是临时文件系统，不是持久磁盘。不同访问码的历史、任务接口和结果页面相互隔离；研究内容不进入Git。
- 每个访问码最近24小时最多3次，全站最多10次；每码最多一个未完成任务，队列最多10项。参数分别为 `VOC_USER_DAILY_LIMIT`、`VOC_GLOBAL_DAILY_LIMIT`。这是次数上限，不是金额硬上限；金额由实际 token 使用决定。失败任务也计数。
- 服务仍运行且数据库还存在时，页面刷新后可显示当前码的任务与历史。免费实例休眠或重启后数据库丢失，任务、结果和次数计数无法恢复；不能把此次数限制作为跨重启的模型费用上限。如果自行使用持久存储，重启只继续排队任务，运行中任务标为中断，不自动重复模型调用。
- 更换 `VOC_SESSION_SECRET` 会使旧会话和访问码对应的历史映射失效。保留并备份此值；日常撤销用户访问只需移除对应访问码。
- 当前免费版适合小范围体验并即时下载；尚未提供长期存储、注册、计费、自助删除、取消任务和无限并发。

## 真实评论从哪里来

蓝图设置 `VOC_COLLECTOR=v2ex`：用 SOV2EX 的公开搜索索引发现主题，再用 V2EX 官方评论 API 获取原文。最多检索两个短关键词、读取4个主题，每主题首个评论页最多纳入8条候选。模型随后逐条审核相关性，允许得到0条相关评论。搜索摘要、主题作者信息、用户头像和个人资料不会作为评论保存。

这只覆盖 V2EX，不能代表汽车之家、小红书、B站或全网。平台的网络限制、限流、搜索覆盖不足会导致失败或空结果，页面和报告会保留说明；不会补造评论或复用仓库示例。用户可在主题中附上明确的公开 V2EX 讨论链接以限定来源。

可替换为自己的真实采集服务：设置 `VOC_COLLECTOR_URL` 和可选的 `VOC_COLLECTOR_TOKEN`，外部服务优先；遵循 [采集 JSON 契约](deepseek.md)。平台授权只能配置在云端私有环境，不复制本机浏览器 Cookie 或个人目录。

## 上线验收

1. `/healthz` 返回200仅表示服务和数据库可访问；`/api/health` 的配置存在也不能证明真实采集成功。
2. 用两个不同访问码验证结果隔离、退出、历史恢复和次数限制。
3. 用一个明确主题发起小规模真实任务，逐条回查来源，检查评论 → 归类 → 洞察 → 数据报告 → MRD → HTML 与下载。确认来源失败时如实展示。
4. 在手机和桌面验证回车、访问码弹窗、任务进度和报告下载；免费版休眠／重启后应提示原任务已不存在，不能承诺旧结果仍能打开。
5. 确认首页源码、镜像、日志和Git历史中没有真实密钥；分享链接前确认Free方案、免费额度和实际云端渠道覆盖。
